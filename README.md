# FRONTLINE

PWA mobile-first pour structurer la visibilité artistique, comparer plusieurs stratégies par plateforme et développer des projets.

## Installation sur iPhone
1. Ouvrir le lien GitHub Pages dans Safari.
2. Partager → Ajouter à l’écran d’accueil.
3. Ouvrir FRONTLINE depuis l’icône.

## Données
Les réponses et choix restent dans le stockage local du navigateur. Aucun serveur ni abonnement n’est requis pour le fonctionnement principal.

## Fichiers
- `index.html` : application
- `manifest.webmanifest` : configuration PWA
- `sw.js` : fonctionnement hors ligne
- `icon.svg` : icône de l’application
